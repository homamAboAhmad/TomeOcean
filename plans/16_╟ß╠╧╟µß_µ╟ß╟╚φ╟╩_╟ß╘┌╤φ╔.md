# خطة 16: تنسيق الجداول والأبيات الشعرية مطابقاً للوورد

## الوصف
إصلاح تنسيق الجداول بحيث يكون مطابقاً لتنسيق الوورد من حيث الحجم والخط وتنسيقه ونوعه والحدود والألوان والمحاذاة. الأبيات الشعرية في Word تُنسَّق عادةً كجداول (عمودين: صدر وعجز)، فإصلاح الجداول يحل مشكلتهما معاً.

## الأولوية: متوسطة
## الوقت المتوقع: 8-10 ساعات

---

## ⛔ قواعد إلزامية قبل التنفيذ
1. **يجب الرجوع إلى** `WordXmlDoumentation/` وقراءة أقسام `w:tbl`، `w:tblPr`، `w:tblGrid`، `w:tr`، `w:trPr`، `w:tc`، `w:tcPr`، `w:tblBorders`، `w:tcBorders`، `w:tblStyle`، `w:tblStylePr`، `w:gridSpan`، `w:vMerge`، `w:tblCellMar`، `w:tblInd`، `w:jc` (محاذاة الجدول) قبل أي تعديل.
2. **ممنوع الحلول الترقيعية**: التعديل يجب أن يتبع مواصفات Word XML بدقة ويعمل على عشرات آلاف الكتب بجداول مختلفة التعقيد.
3. **ممنوع hardcode** لعروض أعمدة أو أنماط أو أحجام خطوط خاصة بكتاب واحد.
4. **وراثة الأنماط**: يجب اتباع سلسلة وراثة التنسيق الصحيحة في Word: (أنماط الجدول `tblStyle` → خصائص الجدول `tblPr` → خصائص الصف `trPr` → خصائص الخلية `tcPr` → التنسيق المباشر).
5. **الاختبار**: اختبار على 5 كتب مختلفة تحتوي جداول بسيطة ومعقدة وأبيات شعرية.
6. **كود نظيف + مبدأ المسؤولية الواحدة (SRP)**: كل ملف/كلاس مسؤول عن شيء واحد فقط. أنشئ ملفات جديدة بدلاً من حشر الكود في ملف موجود. لا تكرر الكود (DRY). الدوال قصيرة وواضحة (40-50 سطراً كحد أقصى). اتبع أسلوب المشروع الحالي. لا تترك كوداً ميتاً أو معلّقاً.

### 1. إصلاح وراثة خصائص الخط في خلايا الجدول (3 ساعات)

#### 1.1 المشكلة
في `getCellWidget()` سطر 325-327:
```dart

```
الفقرة تُحلَّل لكنها قد لا ترث خصائص الخط من نمط الجدول (`tblStyle`).

#### 1.2 سلسلة وراثة الخط في الجدول (حسب مواصفات Word XML)
```
المستوى 1: docDefaults → rPrDefault
المستوى 2: نمط الجدول (tblStyle) → tblStylePr (whole table) → rPr
المستوى 3: نمط الجدول → tblStylePr (band/firstRow/firstCol) → rPr
المستوى 4: نمط الفقرة (pStyle) → rPr
المستوى 5: التنسيق المباشر على النص (w:rPr في w:r)
```

#### 1.3 التعديل المطلوب
**الملف**: `lib/wordToHTML/ParagraphTable.dart` — `getCellWidget()`

قبل بناء الفقرات، استخراج خصائص النص من نمط الجدول وتطبيقها:

دالة جديدة:
```dart
RPr? _getTableStyleRPr(XmlElement? tableStyle, int rowIndex, int colIndex, int totalRows, int totalCols) {
  if (tableStyle == null) return null;
  
  // الأولوية: firstRow > lastRow > firstCol > lastCol > bandX > whole table
  List<String> conditionTypes = [];
  if (rowIndex == 0) conditionTypes.add('firstRow');
  if (rowIndex == totalRows - 1) conditionTypes.add('lastRow');
  if (colIndex == 0) conditionTypes.add('firstCol');
  if (colIndex == totalCols - 1) conditionTypes.add('lastCol');
  if (rowIndex % 2 == 1) conditionTypes.add('band2Horz');
  else conditionTypes.add('band1Horz');
  
  for (String condType in conditionTypes) {
    for (var tblStylePr in tableStyle.findAllElements('w:tblStylePr')) {
      if (tblStylePr.getAttribute('w:type') == condType) {
        var rPrEl = tblStylePr.getElement('w:rPr');
        if (rPrEl != null) {
          return RPr().fromXml(rPrEl);
        }
      }
    }
  }
  
  // Whole table rPr
  var rPrEl = tableStyle.getElement('w:rPr');
  if (rPrEl != null) return RPr().fromXml(rPrEl);
  
  return null;
}
```

#### 1.4 إصلاح مشكلة Bold في الخلايا
المشكلة المعروفة: النص العريض لا يظهر في بعض الخلايا.

السبب: `tblStylePr` لـ `firstRow` قد يحدد `<w:b/>` لكنه لا يُطبَّق.
الحل: تمرير `styleRPr` كـ fallback في `RPr.fromXml()`:
```dart
void _applyTableStyleRPr(Paragraph paragraph, RPr? styleRPr) {
  if (styleRPr == null) return;
  for (var run in paragraph.runs) {
    // فقط إذا لم يكن لديه تنسيق مباشر
    run.rpr ??= RPr();
    run.rpr!.bold ??= styleRPr.bold;
    run.rpr!.italic ??= styleRPr.italic;
    run.rpr!.fontSize ??= styleRPr.fontSize;
    run.rpr!.fontFamily ??= styleRPr.fontFamily;
    run.rpr!.color ??= styleRPr.color;
  }
}
```

### 3. إصلاح أبعاد الخلايا (1.5 ساعة)

#### 3.1 هوامش الخلايا (Cell Margins)
**مفقود حالياً**: `w:tblCellMar` و `w:tcMar` لا تُقرأ.

التعديل:
```dart
EdgeInsets _getCellMargins(XmlElement cell) {
  // الأولوية 1: هوامش الخلية المباشرة
  var tcMar = cell.getElement('w:tcPr')?.getElement('w:tcMar');
  
  // الأولوية 2: هوامش الجدول
  tcMar ??= tblXml.getElement('w:tblPr')?.getElement('w:tblCellMar');
  
  // الأولوية 3: هوامش من نمط الجدول
  if (tcMar == null) {
    String? styleId = _getTableStyleId();
    if (styleId != null) {
      var style = getDocumentStyle(styleId, parent.parent);
      tcMar = style?.getElement('w:tblPr')?.getElement('w:tblCellMar');
    }
  }
  
  if (tcMar == null) return EdgeInsets.symmetric(horizontal: 5.4 * 0.0667);
  
  double top = _parseTwips(tcMar.getElement('w:top')?.getAttribute('w:w'));
  double bottom = _parseTwips(tcMar.getElement('w:bottom')?.getAttribute('w:w'));
  double start = _parseTwips(tcMar.getElement('w:start')?.getAttribute('w:w') 
      ?? tcMar.getElement('w:left')?.getAttribute('w:w'));
  double end = _parseTwips(tcMar.getElement('w:end')?.getAttribute('w:w')
      ?? tcMar.getElement('w:right')?.getAttribute('w:w'));
  
  return EdgeInsets.fromLTRB(start, top, end, bottom);
}

double _parseTwips(String? val) {
  if (val == null) return 0;
  return (double.tryParse(val) ?? 0) * 0.0667; // twips to pixels
}
```

تطبيق في `getCellWidget()`:
```dart
return Container(
  width: cellWidthPx,
  decoration: decoration,
  padding: _getCellMargins(rowCell),  // بدلاً من EdgeInsets.symmetric(horizontal: 1)
  child: Align(alignment: verticalAlign, child: cellContent),
);
```

```dart
// تتبع الخلايا المدمجة عمودياً
Map<int, int> vMergeSpans = {}; // gridColIndex → عدد الصفوف المتبقية

for (int rowIndex = 0; rowIndex < rows.length; rowIndex++) {
  var row = rows[rowIndex];
  List<XmlElement> rowCells = row.childElements
      .where((n) => n.name.local == 'tc').toList();

  for (var cell in rowCells) {
    var vMerge = cell.getElement('w:tcPr')?.getElement('w:vMerge');
    int span = _getGridSpan(cell);

      String? val = vMerge.getAttribute('w:val');
```
