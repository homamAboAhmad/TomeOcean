# خطة 11: النسخ المتقدم (عدة فقرات + توثيق مرجعي)

## الوصف
إتاحة نسخ أكثر من فقرة في نفس الوقت، وتنسيق النص المنسوخ بصيغة مرجعية:
`«النص المنسوخ» [اسم الكتاب (ص 76)]`

## الأولوية: متوسطة
## الوقت المتوقع: 4-6 ساعات

## السياق التقني

### النظام الحالي
1. **النسخ العادي**: Flutter `SelectionArea` يتيح تحديد ونسخ نص من فقرة واحدة.
2. **النسخ مع المرجع** (`WordPageScreen.dart` سطر 20-58):
   - `CopyWithReferenceAction` مربوط بـ `Ctrl+Shift+C`
   - ينسخ النص المحدد ويضيف: `\n[عنوان_الكتاب، صفحة X]`
3. **قائمة السياق** (`custom_context_menu.dart` سطر 27-33):
   - `_handleCopyReference()` ينسخ بصيغة: `"النص"\n(عنوان_الكتاب، رقم_الصفحة)`
4. **المشكلة**: لا يمكن تحديد نص يمتد عبر عدة فقرات (كل `SelectionArea` مستقلة).

### 2. تعديل صيغة النسخ مع المرجع (1.5 ساعة)

#### 2.1 الصيغة المطلوبة
المستخدم طلب الصيغة التالية:
```
«النص المنسوخ» [اسم الكتاب (ص 76)]
```
مثال كامل: `«النص المنسوخ هنا» [موقف القرآن من خصومه (ص 44)]`

#### 2.2 تعديل CopyWithReferenceAction
**الملف**: `lib/UI/WordPageScreen.dart` سطر 30-58

```dart
@override
Object? invoke(CopyWithReferenceIntent intent) async {
  final primaryContext = primaryFocus?.context;
  if (primaryContext == null) return null;

  Actions.invoke(primaryContext, CopySelectionTextIntent.copy);
  await Future.delayed(const Duration(milliseconds: 50));

  final clipboardData = await Clipboard.getData(Clipboard.kTextPlain);
  final selectedText = clipboardData?.text;

  if (selectedText == null || selectedText.isEmpty) return null;

  // الصيغة الجديدة: «النص» [الكتاب (ص X)]
  final String bookTitle = wordPage.parent.title;
  final int pageNum = wordPage.parent.currentPage + 1;
  final String textWithReference = 
      '«$selectedText» [$bookTitle (ص $pageNum)]';
  
  await Clipboard.setData(ClipboardData(text: textWithReference));
  return null;
}
```

#### 2.3 تعديل قائمة السياق
**الملف**: `lib/UI/custom_context_menu.dart` سطر 27-33

```dart
void _handleCopyReference() {
  final String? text = selectedText;
  if (text != null && text.isNotEmpty) {
    final String textToCopy = '«$text» [$bookTitle (ص $pageNumber)]';
    Clipboard.setData(ClipboardData(text: textToCopy));
    state.hideToolbar();
  }
}
```

### 3. نسخ عادي (بدون مرجع) لعدة فقرات (0.5 ساعة)
- `Ctrl+C` العادي يجب أن يعمل على النص المحدد عبر عدة فقرات
- هذا يعمل تلقائياً إذا كانت `SelectionArea` واحدة تلف الكل

### 4. إضافة خيار "نسخ صفحة كاملة" (1 ساعة)

#### 4.1 في شريط الأدوات
حالياً يوجد زر `onCopyPage` في `DocViewerTopToolbar`. تعديل ليستخدم الصيغة الجديدة:

**الملف**: `lib/UI/DocViewer.dart`
```dart
void _copyPage() {
  // جمع نص جميع فقرات الصفحة الحالية
  WordPage page = widget.wordDocument.getPage(widget.wordDocument.currentPage);
  String fullText = page.ps.map((p) => p.text).join('\n');
  
  String bookTitle = widget.wordDocument.title;
  int pageNum = widget.wordDocument.currentPage + 1;
  String textWithRef = '«$fullText» [$bookTitle (ص $pageNum)]';
  
  Clipboard.setData(ClipboardData(text: textWithRef));
}
```
