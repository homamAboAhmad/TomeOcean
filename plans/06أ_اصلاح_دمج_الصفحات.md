عندما تمتد فقرة واحدة عبر صفحتين (مثلاً ص54 و ص55)، يدمج التطبيق محتوى الصفحتين في صفحة واحدة بدلاً من فصلهما.

## تشخيص المشكلة (مكتمل)

### ما يحدث حالياً
في كتاب "السيرة النبوية الفرنسية"، الصفحتان 54-55 مدمجتان في صفحة واحدة.

### السبب الجذري
المشكلة في **مرحلتين**:

#### المرحلة 1: سكريبت Python (`scripts/pageRender.py`)
- الدالة `process_xml_with_page_breaks` تبحث عن `ShamelaPage_X` bookmarks في كل فقرة.
- **المشكلة**: الكود يأخذ `bookmarks_in_para[0]` (أول bookmark فقط) ويتجاهل بقية الـ bookmarks.
- عندما تمتد فقرة عبر صفحتين، تحتوي على **بوكماركين**: `ShamelaPage_54` (في البداية) و `ShamelaPage_55` (في المنتصف).
- **النتيجة**: يُحقن ماركر `{{PG:54}}` فقط، ولا يُحقن `{{PG:55}}` في نفس الفقرة.

#### المرحلة 2: Dart (`lib/Utils/WordUtils.dart`)
- الدالة `_groupParagraphsByPage` تبحث عن `{{PG:X}}` markers.
- بما أن الفقرة الطويلة تحتوي فقط على `{{PG:54}}`، يُضاف كل محتواها للصفحة 54.
- حتى لو كان هناك `{{PG:55}}` في فقرة لاحقة، فإن **النص الذي يجب أن يكون في ص55** بقي ملتصقاً بالفقرة الأولى في ص54.

### مثال توضيحي من XML الفعلي
```
الفقرة 0 (Paragraph 0):
├── {{PG:54}}      ← ماركر الصفحة 54 ✅
├── [نص طويل...]
├── ShamelaPage_55 bookmark  ← بوكمارك الصفحة 55 (لم يُحقن ماركر!)
├── lastRenderedPageBreak    ← فاصل الصفحة المرئي
├── [نص يجب أن يكون في ص55...]  ← ❌ هذا النص يظهر في ص54 خطأً
```

**المطلوب:**
```
الفقرة 0 - الجزء الأول (ص54):
├── {{PG:54}}
├── [نص ص54...]

الفقرة 0 - الجزء الثاني (ص55):
├── {{PG:55}}
├── [نص ص55...]
```

**التفاصيل الكاملة للتعديل:**

1. استبدال السطر 338 (`target_bookmark = bookmarks_in_para[0]`) بحلقة `for` تمر على كل الـ bookmarks.

2. نقل معالجة كل bookmark داخل الحلقة:
   - كل bookmark يُعالج بنفس الطريقة الحالية (حالة inside run، أو حالة direct child).
   - مع تتبع `current_page` لكل bookmark.

3. **ملاحظة مهمة**: يجب تحديث `direct_children = list(para)` **داخل** الحلقة (وليس خارجها) لأن الفقرة تتغير بعد كل حقن.

**الكود الكامل البديل** (استبدال السطور 334-414):

```python

    # ترتيب الـ bookmarks حسب رقم الصفحة (الأصغر أولاً)
    bookmarks_in_para.sort(
        key=lambda bm: int(bm.attrib.get(f"{{{NS['w']}}}name", "ShamelaPage_0").split("_")[1])
    )
    
    # معالجة كل bookmark
    for target_bookmark in bookmarks_in_para:
        bm_name = target_bookmark.attrib.get(f"{{{NS['w']}}}name", "")
        
        # استخراج رقم الصفحة
        try:
            new_page_num = int(bm_name.split("_")[1])
            current_page = new_page_num
        except:
            continue

        # تقسيم الـ run عند Bookmark وحقن marker
        bm_parent = target_bookmark.getparent()
        
        # حالة: Bookmark inside a Run
        if bm_parent is not None and bm_parent.tag == f"{{{NS['w']}}}r":
            from copy import deepcopy
            
            bm_run = bm_parent
            run_before = ET.Element(f"{{{NS['w']}}}r")
            run_after = ET.Element(f"{{{NS['w']}}}r")
            
            found_bm = False
            rPr = bm_run.find(f"{{{NS['w']}}}rPr")
            
            if rPr is not None:
                run_before.append(deepcopy(rPr))
                run_after.append(deepcopy(rPr))
            
            for child in list(bm_run):
                if child.tag == f"{{{NS['w']}}}rPr":
                    continue
                elif child == target_bookmark:
                    found_bm = True
                    run_before.append(deepcopy(child))
                elif not found_bm:
                    run_before.append(deepcopy(child))
                else:
                    run_after.append(deepcopy(child))
            
            # إيجاد موقع bm_run في الفقرة (تحديث القائمة كل مرة)
            direct_children = list(para)
            for i, child in enumerate(direct_children):
                if child == bm_run:
                    para.remove(bm_run)
                    
                    has_before_content = len([c for c in run_before if c.tag != f"{{{NS['w']}}}rPr"]) > 0
                    if has_before_content:
                        para.insert(i, run_before)
                        i += 1
                    
                    marker_after = create_hidden_run_element(f"{{{{PG:{current_page}}}}}")
                    para.insert(i, marker_after)
                    i += 1
                    injected_count += 1
                    
                    has_after_content = len([c for c in run_after if c.tag != f"{{{NS['w']}}}rPr"]) > 0
                    if has_after_content:
                        para.insert(i, run_after)
                    
                    break
        
        # حالة: Bookmark direct child of Paragraph
        else:
            direct_children = list(para)
            for i, child in enumerate(direct_children):
                if child == target_bookmark:
                    marker = create_hidden_run_element(f"{{{{PG:{current_page}}}}}")
                    para.insert(i + 1, marker)
```
