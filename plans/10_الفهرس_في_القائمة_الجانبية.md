# خطة 10: الفهرس في القائمة الجانبية

## الوصف
إصلاح عدم ظهور فهرس الكتاب في الشريط الجانبي، والحفاظ على التدرج الهرمي للعناوين (رئيسية/فرعية) كما في الملف الأصلي.

## الأولوية: متوسطة
## الوقت المتوقع: 6-8 ساعات

---

## ⛔ قواعد إلزامية قبل التنفيذ
1. **يجب الرجوع إلى** `WordXmlDoumentation/` وقراءة أقسام `w:pStyle` (أنماط الفقرات)، `Heading` styles، و `w:sdt` (Structured Document Tags للفهرس) قبل أي تعديل على اكتشاف العناوين.
2. **ممنوع الحلول الترقيعية**: اكتشاف العناوين يجب أن يعمل مع جميع أنماط Word (إنجليزية وعربية ومخصصة) وليس قائمة ثابتة.
3. **ممنوع hardcode** لأسماء أنماط خاصة بكتاب واحد.
4. **الاختبار**: يجب اختبار على 5 كتب مختلفة (كتب بفهرس وبدون، كتب بعناوين عربية وإنجليزية).
5. **كود نظيف + مبدأ المسؤولية الواحدة (SRP)**: كل ملف/كلاس مسؤول عن شيء واحد فقط. أنشئ ملفات جديدة بدلاً من حشر الكود في ملف موجود. لا تكرر الكود (DRY). الدوال قصيرة وواضحة (40-50 سطراً كحد أقصى). اتبع أسلوب المشروع الحالي. لا تترك كوداً ميتاً أو معلّقاً.

---

## السياق التقني

### كيف يعمل الفهرس حالياً
1. **استخراج العناوين** (`IndexController.dart` سطر 11-24):
   - يفحص كل فقرة عند التحليل عبر `addIndexIfExisted()`
   - يبحث عن `w:pStyle` يبدأ بـ `heading` (مثل `Heading1`, `Heading2`)
   - يضيف `IndexItem(title, page, type)` إلى `WordDocument.index`
2. **عرض الفهرس** (`BookIndexUI.dart`):
   - يعرض `WordDocument.index` كقائمة قابلة للطي
   - `Heading1` = عنوان رئيسي، البقية = فرعي
3. **الشريط الجانبي** (`BooksSideBarIcons.dart`):
   - أيقونة "فهرس الكتاب" (index 0) تعرض `BookIndexUI`

### المشاكل المحتملة
- **الفهرس فارغ**: `IndexController.addIndexIfExisted()` لا يكتشف العناوين لأن:
  - الأنماط العربية (مثل `عنوان1`) لا تُكتشف (يبحث فقط عن `heading`)
  - بعض المستندات تستخدم تنسيقاً يدوياً بدلاً من أنماط Heading
  - الفهرس لا يُحفظ في الكاش (`index` ليست في `metadata.json`)
- **التدرج مفقود**: في السيرة الفرنسية "الفهرس ص 3 العنوان الرئيسي والفرعي كلها سواسية"

## الخطوات التفصيلية

### 1. إصلاح اكتشاف العناوين (2 ساعة)

#### 1.1 توسيع أنماط العناوين المكتشفة
**الملف**: `lib/Controllers/IndexController.dart`

الكود الحالي (سطر 15):
```dart
if (styleVal != element && styleVal!.toLowerCase().startsWith('heading')) {
```

**التعديل المطلوب** — إضافة الأنماط العربية والأنماط الشائعة:
```dart
addIndexIfExisted(XmlElement element, int pageNum) {
  final styleEl = element.findAllElements('w:pStyle').firstOrNull;
  if (styleEl != null) {
    final styleVal = styleEl.getAttribute('w:val');
    if (styleVal != null) {
      String styleLower = styleVal.toLowerCase();
      String? headingType = _detectHeadingType(styleLower);
      if (headingType != null) {
        final text = element.findAllElements('w:t')
            .map((e) => e.text).join('').trim();
        if (text.isNotEmpty) {
          IndexItem item = IndexItem(
            title: text,
            page: pageNum,
            type: headingType,
            id: '${pageNum}_${_wordDocument.index.length}',
          );
          _wordDocument.index.add(item);
        }
      }
    }
  }
}

String? _detectHeadingType(String styleLower) {
  // أنماط Heading الإنجليزية: heading1, heading2, ...
  if (styleLower.startsWith('heading')) {
    RegExp regex = RegExp(r'heading\s*(\d)');
    Match? match = regex.firstMatch(styleLower);
    if (match != null) return 'Heading${match.group(1)}';
    return 'Heading1';
  }
  // أنماط TOC: toc1, toc2, ...
  if (styleLower.startsWith('toc')) {
    RegExp regex = RegExp(r'toc\s*(\d)');
    Match? match = regex.firstMatch(styleLower);
    if (match != null) return 'Heading${match.group(1)}';
  }
  // أنماط Title/Subtitle
  if (styleLower == 'title') return 'Heading1';
  if (styleLower == 'subtitle') return 'Heading2';
  // أنماط عربية
  if (styleLower.contains('عنوان')) return 'Heading1';
  if (styleLower.contains('فصل')) return 'Heading1';
  if (styleLower.contains('باب')) return 'Heading1';
  if (styleLower.contains('مبحث')) return 'Heading2';
  if (styleLower.contains('مطلب')) return 'Heading2';
  if (styleLower.contains('فرع')) return 'Heading3';
  if (styleLower.contains('مسألة')) return 'Heading3';
  return null;
}
```

#### 1.2 اكتشاف العناوين بالتنسيق (بدون أنماط)
بعض المستندات لا تستخدم أنماط Heading بل تنسيقاً يدوياً (خط عريض + حجم كبير). إضافة اكتشاف اختياري:
```dart
// إذا لم يُكتشف نمط heading، فحص التنسيق اليدوي:
// - خط عريض (bold)
// - حجم خط أكبر من المتوسط
// - محاذاة وسطية
// هذا اختياري ويمكن تفعيله بإعداد
```

### 3. إصلاح التدرج الهرمي في العرض (2 ساعة)

#### 3.1 تعديل BookIndexUI.dart
**المشكلة**: حالياً فقط `Heading1` يُعتبر عنواناً رئيسياً، والبقية فرعي.
**التعديل**: دعم مستويات متعددة مع مسافات بادئة:

```dart
// تعديل setIndexMap() لدعم تدرج أعمق
void setIndexMap() {
  List<IndexItem> index = widget.wordDocument.index;
  subItems.clear();
  
  IndexItem? lastH1;
  IndexItem? lastH2;
  
  for (int i = 0; i < index.length; i++) {
    IndexItem item = index[i];
    int level = _getHeadingLevel(item.type); // 1, 2, 3, ...
    
    if (level == 1) {
      lastH1 = item;
      lastH2 = null;
      subItems[lastH1] = [];
    } else if (level == 2 && lastH1 != null) {
      lastH2 = item;
      subItems[lastH1]!.add(item);
      // تخزين فرعي من المستوى 3 تحت المستوى 2
      subItems[lastH2] = [];
    } else if (level >= 3 && lastH2 != null) {
      subItems[lastH2]!.add(item);
    } else if (lastH1 != null) {
      subItems[lastH1]!.add(item);
    }
  }
}

int _getHeadingLevel(String type) {
  RegExp regex = RegExp(r'Heading(\d)');
  Match? match = regex.firstMatch(type);
  if (match != null) return int.parse(match.group(1)!);
  return 1;
}
```

#### 3.2 عرض المسافات البادئة حسب المستوى
```dart
// تعديل getHeadingPadding():
getHeadingPadding(IndexItem e) {
  int level = _getHeadingLevel(e.type);
  // المستوى 1 = 0px، المستوى 2 = 20px، المستوى 3 = 40px
  return SizedBox(width: (level - 1) * 20.0);
}
```
