### 1. تحميل البيانات الوصفية في isolate (2 ساعة)

#### 1.1 نقل التحليل الثقيل إلى Isolate
**الملف**: `lib/Services/BookProcessingService.dart`

حالياً `_parseAndCacheBookInternal()` يعمل على main thread.
التعديل: نقل العمليات الثقيلة إلى `Isolate.run()`:

```dart
/// تحليل الكتاب في isolate منفصل
Future<WordDocument> _parseInBackground(String filePath) async {
  return await Isolate.run(() {
    // قراءة الأرشيف
    Archive archive = fileToArchive(filePath);
    // تحليل XML
    WordDocument doc = WordDocument();
    AddDocData(archive, doc);
    // تحليل الصفحات
    WordUtils wordUtils = WordUtils(doc);
    wordUtils.parsePages();
    return doc;
  });
}
```

**ملاحظة مهمة**: `Isolate.run()` لا يشارك الذاكرة — يجب أن تكون البيانات المرسلة والمستقبلة قابلة للتسلسل (serializable). فحص `WordDocument` والتأكد من أن `toJson()/fromJson()` يعملان.

### 3. التحميل الكسول للصفحات (2 ساعة)

#### 3.1 الوضع الحالي
عند فتح كتاب من الكاش، تُحمَّل **جميع** الصفحات من ملفات JSON.gz.
كتاب بـ 580 صفحة = 580 عملية قراءة + فك ضغط + تحليل JSON.

#### 3.2 التحميل عند الطلب (Lazy Loading)
**الملف**: `lib/Models/WordDocument.dart`

```dart
/// خريطة الصفحات المحمّلة (كاش في الذاكرة)
@JsonKey(ignore: true)
Map<int, WordPage> _pageCache = {};

/// تحميل صفحة عند الطلب
Future<WordPage> getPage(int index) async {
  // إذا محمّلة مسبقاً
  if (_pageCache.containsKey(index)) return _pageCache[index]!;
  
  // تحميل من الملف
  String pagePath = '${cacheDir}/pages/$index.json.gz';
  File file = File(pagePath);
  if (!await file.exists()) throw Exception('صفحة $index غير موجودة');
  
  List<int> compressed = await file.readAsBytes();
  List<int> jsonBytes = gzip.decode(compressed);
  String jsonStr = utf8.decode(jsonBytes);
  Map<String, dynamic> json = jsonDecode(jsonStr);
  
  WordPage page = WordPage.fromJson(json);
  page.parent = this;
  _pageCache[index] = page;
  
  return page;
}
```

#### 3.3 تعديل DocViewer لدعم التحميل الكسول

بدلاً من تمرير `WordPage` مباشرة، استخدام `FutureBuilder`:
```dart
Widget _buildPage(int index) {
  return FutureBuilder<WordPage>(
    future: widget.wordDocument.getPage(index),
    builder: (context, snapshot) {
      if (snapshot.connectionState == ConnectionState.waiting) {
        return SizedBox(
          height: pageHeight,
          child: Center(child: CircularProgressIndicator()),
        );
      }
      if (snapshot.hasError) {
        return SizedBox(
          height: pageHeight,
          child: Center(child: Text('خطأ في تحميل الصفحة')),
        );
      }
      return WordPageScreen(wordPage: snapshot.data!);
    },
  );
}
```

### 4. التحميل المسبق (Pre-fetching) (1 ساعة)

#### 4.1 تحميل الصفحات المجاورة مسبقاً
```dart
/// تحميل مسبق للصفحات المحيطة بالصفحة الحالية
void prefetchPages(int currentPage) {
  // تحميل 3 صفحات قبل و3 بعد
  for (int i = currentPage - 3; i <= currentPage + 3; i++) {
    if (i >= 0 && i < pageFilePaths.length && !_pageCache.containsKey(i)) {
      getPage(i); // يعمل في الخلفية
    }
  }
}
```

#### 4.2 تحديد حجم الكاش
```dart
static const int MAX_CACHED_PAGES = 50;

void _evictOldPages(int currentPage) {
  if (_pageCache.length <= MAX_CACHED_PAGES) return;
  
  // حذف الصفحات الأبعد عن الصفحة الحالية
  var sortedKeys = _pageCache.keys.toList()
    ..sort((a, b) => (a - currentPage).abs().compareTo((b - currentPage).abs()));
  
  while (_pageCache.length > MAX_CACHED_PAGES) {
    _pageCache.remove(sortedKeys.removeLast());
  }
}
```
