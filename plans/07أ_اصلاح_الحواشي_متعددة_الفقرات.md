# خطة 7أ: إصلاح الحواشي السفلية (3 مشاكل)

## الوصف

إصلاح ثلاث مشاكل في نظام الحواشي السفلية:

1. **حذف الحواشي متعددة الفقرات** (حرجة) — التطبيق يأخذ أول فقرة فقط من كل حاشية ويحذف الباقي
2. **الخط الفاصل ملاصق للنص** (متوسطة) — الخط الفاصل حالياً ملاصق لآخر سطر في المتن بدلاً من أن يكون فوق الحاشية مباشرة
3. **تنسيق أرقام الحواشي** (متوسطة) — الرقم يجب أن يكون حسب لغة النص المجاور له

> [!NOTE]
> المشكلة الرابعة (الأسطر الفارغة بين الحواشي) مؤجلة حتى توفر بيانات أكثر.

## الأولوية: عالية
## الوقت المتوقع: 4-5 ساعات

---

## ⛔ قواعد إلزامية قبل التنفيذ

1. **ممنوع الحلول الترقيعية**: الحل يجب أن يعمل على عشرات آلاف الكتب
2. **ممنوع hardcode** لعدد فقرات أو أنماط خاصة بكتاب واحد
3. **التوافق العكسي**: الكاش القديم (حاشية بفقرة `p` واحدة) يجب أن يستمر بالعمل بدون كسر
4. **كود نظيف + SRP**: دوال قصيرة، لا تكرار، أسماء واضحة
5. **لا تُغيّر سلوك أي شيء لا علاقة له بهذه المشاكل**

```dart
FootNote _$FootNoteFromJson(Map<String, dynamic> json) {
  final footNote = FootNote.empty();
  footNote.id = json['id'] as String;
  footNote.displayNumber = json['displayNumber'] as String?;

        .toList();

    footNote.paragraphs = [
      Paragraph.fromJson(json['p'] as Map<String, dynamic>)
    ];
  }

  return footNote;
}

Map<String, dynamic> _$FootNoteToJson(FootNote instance) => <String, dynamic>{
  'paragraphs': instance.paragraphs.map((e) => e.toJson()).toList(),
  'id': instance.id,
  'displayNumber': instance.displayNumber,
```

## المشكلة 3: تنسيق أرقام الحواشي حسب لغة النص المجاور (0.5 ساعة)

### الوضع الحالي

في [WordUtils.dart](file:///d:/ImportantProjects/golden_shamela/lib/Utils/WordUtils.dart) الأسطر 95-116:

```dart
// الكود الحالي:

  isFootnoteArabic = isArabicText(footNote.p.text);  // لغة الحاشية كاملة

  bodyNum = toArabicNumbers(bodyNum);

  footerNum = toArabicNumbers(footerNum);
```

### المشكلة

المنطق يعتمد على لغة **الفقرة الكاملة** أو **الحاشية الكاملة**. المطلوب: الرقم يكون حسب لغة **النص المجاور مباشرة** للرقم.

### الحل

**لرقم المتن** (inline reference): فحص النص المجاور للـ run (الـ run السابق أو اللاحق):

```dart
// بدلاً من:
bool isBodyArabic = isArabicText(p.text);

// نفحص النص المحيط بالـ run مباشرة:
String surroundingText = _getSurroundingText(p.runs, runIndex);
bool isBodyArabic = isArabicText(surroundingText);
```

**أضف دالة مساعدة** في نفس الكلاس:

```dart
/// استخراج النص المحيط بـ run معين لتحديد لغة السياق
String _getSurroundingText(List<runT> runs, int index) {
  String text = '';
  // النص من الـ run السابق
  if (index > 0 && runs[index - 1].text != null) {
    text += runs[index - 1].text!;
  }
  // النص من الـ run اللاحق
  if (index < runs.length - 1 && runs[index + 1].text != null) {
    text += runs[index + 1].text!;
  }
  // إذا لم يوجد نص محيط، نرجع لنص الفقرة
  if (text.trim().isEmpty) {
    for (var r in runs) {
      if (r.text != null) text += r.text!;
    }
  }
  return text;
}
```

**لرقم الحاشية** (footer reference): نفس المبدأ — الرقم يتبع لغة نص الحاشية المجاور:

```dart
// رقم الحاشية يتبع لغة النص المجاور في الحاشية
if (footNote != null && footNote.text.isNotEmpty) {
  isFootnoteArabic = isArabicText(footNote.text);
}
// رقم الحاشية يتبع لغة نصها (وليس لغة المتن)
if (isFootnoteArabic) {
  footerNum = toArabicNumbers(footerNum);
}
```

> [!IMPORTANT]
> التعديل الأهم: **إزالة** شرط `|| isBodyArabic` من تحويل رقم الحاشية. الرقم في الحاشية يتبع لغة **نص الحاشية** فقط وليس لغة المتن.

## خطة التحقق

### 1. التحقق من البناء
```
flutter build windows
```
يجب أن ينجح بدون أخطاء.

### 2. التحقق من التوافق العكسي
- فتح كتاب **محمّل مسبقاً من الكاش القديم** — يجب أن يعمل بدون أخطاء وتظهر الحواشي كما كانت

### 3. التحقق من المشكلة 1 (الحواشي متعددة الفقرات)
- فتح كتاب يحتوي على حواشٍ طويلة (مثل: حوار هادئ مع الصوفية)
- مقارنة محتوى الحاشية مع نفس الصفحة في Microsoft Word
- التأكد من ظهور **كل فقرات** الحاشية وليس الأولى فقط

### 4. التحقق من المشكلة 2 (الخط الفاصل)
- التأكد بصرياً أن الخط الفاصل يظهر **فوق الحواشي مباشرة** وليس ملاصقاً لآخر سطر في المتن

### 5. التحقق من المشكلة 3 (تنسيق الأرقام)
- فحص كتاب عربي: الأرقام يجب أن تكون عربية
- فحص كتاب إنجليزي أو مختلط: الأرقام تتبع لغة النص المجاور
