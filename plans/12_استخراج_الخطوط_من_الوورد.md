# خطة 12: استخراج الخطوط المدمجة من ملفات الوورد

## الوصف
سحب الخطوط المدمجة مباشرة من ملف الوورد (docx) وتحميلها ديناميكياً عند فتح الكتاب، مما يحل مشاكل عرض آيات القرآن والحروف المقطعة وأي خط غير متوفر على جهاز المستخدم.

## الأولوية: عالية
## الوقت المتوقع: 8-10 ساعات

---

## ⛔ قواعد إلزامية قبل التنفيذ
1. **يجب الرجوع إلى** `WordXmlDoumentation/` وقراءة أقسام `w:fonts`، `w:embedRegular`، `w:embedBold`، `w:embedItalic`، `w:embedBoldItalic`، و `word/fontTable.xml` قبل أي تعديل.
2. **ممنوع الحلول الترقيعية**: الحل يجب أن يستخرج أي خط مدمج من أي ملف docx تلقائياً، وليس قائمة ثابتة من الخطوط.
3. **ممنوع hardcode** لأسماء خطوط معينة.
4. **الأداء**: استخراج الخطوط يجب ألا يبطئ فتح الكتاب. استخدام كاش محلي للخطوط المستخرجة.
5. **الأمان**: بعض الخطوط محمية (`w:fontKey`). يجب التعامل معها بشكل صحيح (تسجيل تحذير دون توقف).
6. **الاختبار**: اختبار على كتب تحتوي خطوط قرآنية مدمجة وكتب بدون خطوط مدمجة.
7. **كود نظيف + مبدأ المسؤولية الواحدة (SRP)**: كل ملف/كلاس مسؤول عن شيء واحد فقط. أنشئ ملفات جديدة بدلاً من حشر الكود في ملف موجود. لا تكرر الكود (DRY). الدوال قصيرة وواضحة (40-50 سطراً كحد أقصى). اتبع أسلوب المشروع الحالي. لا تترك كوداً ميتاً أو معلّقاً.

---

## السياق التقني

### بنية الخطوط في docx
ملف `word/fontTable.xml` يحتوي على تعريف كل خط مستخدم في المستند:
```xml
<w:font w:name="KFGQPC Uthmanic Script HAFS">
  <w:embedRegular w:fontKey="{...}" r:id="rId1" w:subsetted="true"/>
  <w:embedBold w:fontKey="{...}" r:id="rId2"/>
</w:font>
```

الخطوط المدمجة فعلياً تُخزن في مجلد `word/fonts/` داخل أرشيف ZIP:
```
word/fonts/font1.odttf   ← خط مشفر/عادي
word/fonts/font2.odttf
```

`r:id` يشير إلى العلاقة في `word/_rels/fontTable.xml.rels` التي تحدد مسار الملف.

### النظام الحالي
- `FontsLoaderController.dart` يحمّل قائمة ثابتة من الخطوط من `assets/fonts/`
- `DocFonts.dart` يقرأ أسماء الخطوط فقط ولا يستخرج الملفات المدمجة
- الخطوط غير الموجودة في `assets/fonts/` لا تُعرض بشكل صحيح

## الخطوات التفصيلية

### 1. استخراج الخطوط المدمجة من الأرشيف (3 ساعات)

#### 1.1 قراءة fontTable.xml والعلاقات
**إنشاء ملف**: `lib/Services/EmbeddedFontExtractor.dart`

```dart
class EmbeddedFontExtractor {
  /// يستخرج الخطوط المدمجة من أرشيف docx
  /// يُرجع Map<اسم_الخط, مسار_الملف_المحلي>
  static Future<Map<String, String>> extractEmbeddedFonts(
    Archive archive,
    String bookCacheDir,
  ) async {
    Map<String, String> extractedFonts = {};
    Map<String, ArchiveFile> archiveMap = archive.toMap();
    
    // 1. قراءة fontTable.xml
    ArchiveFile? fontTableFile = archiveMap['word/fontTable.xml'];
    if (fontTableFile == null) return extractedFonts;
    
    XmlDocument fontTableDoc = ArchiveToXml(fontTableFile);
    
    // 2. قراءة العلاقات
    ArchiveFile? relsFile = archiveMap['word/_rels/fontTable.xml.rels'];
    Map<String, String> relsMap = {};
    if (relsFile != null) {
      XmlDocument relsDoc = ArchiveToXml(relsFile);
      for (var rel in relsDoc.findAllElements('Relationship')) {
        String? id = rel.getAttribute('Id');
        String? target = rel.getAttribute('Target');
        if (id != null && target != null) {
          relsMap[id] = target;
        }
      }
    }
    
    // 3. لكل خط مدمج: استخراج الملف
    var fontsDir = Directory('$bookCacheDir/fonts');
    await fontsDir.create(recursive: true);
    
    for (var fontEl in fontTableDoc.findAllElements('w:font')) {
      String? fontName = fontEl.getAttribute('w:name');
      if (fontName == null) continue;
      
      // فحص كل نوع تضمين
      for (String embedType in [
        'w:embedRegular', 'w:embedBold', 
        'w:embedItalic', 'w:embedBoldItalic'
      ]) {
        var embedEl = fontEl.getElement(embedType);
        if (embedEl == null) continue;
        
        String? rId = embedEl.getAttribute('r:id');
        String? fontKey = embedEl.getAttribute('w:fontKey');
        
        if (rId == null) continue;
        String? targetPath = relsMap[rId];
        if (targetPath == null) continue;
        
        // المسار الكامل داخل الأرشيف
        String fullPath = targetPath.startsWith('/')
            ? targetPath.substring(1) 
            : 'word/$targetPath';
        
        ArchiveFile? fontFile = archiveMap[fullPath];
        if (fontFile == null) continue;
        
        // حفظ الملف محلياً
        String localPath = '${fontsDir.path}/${fontName}_$embedType.ttf';
        await File(localPath).writeAsBytes(
          _deobfuscateFont(fontFile.content, fontKey)
        );
        
        extractedFonts[fontName] = localPath;
      }
    }
    
    return extractedFonts;
  }
  
  /// فك تشفير الخطوط المحمية (ODTTF format)
  /// Word يستخدم XOR مع fontKey لأول 32 بايت
  static List<int> _deobfuscateFont(List<int> data, String? fontKey) {
    if (fontKey == null || fontKey.isEmpty) return data;
    
    // تحويل fontKey GUID إلى بايتات
    // الصيغة: {XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}
    String cleanKey = fontKey
        .replaceAll('{', '')
        .replaceAll('}', '')
        .replaceAll('-', '');
    
    if (cleanKey.length != 32) return data;
    
    List<int> keyBytes = [];
    for (int i = 0; i < cleanKey.length; i += 2) {
      keyBytes.add(int.parse(cleanKey.substring(i, i + 2), radix: 16));
    }
    
    // XOR أول 32 بايت مع المفتاح (مكرر)
    List<int> result = List.from(data);
    for (int i = 0; i < 32 && i < result.length; i++) {
      result[i] = result[i] ^ keyBytes[i % keyBytes.length];
    }
    
    return result;
  }
}
```

### 2. تحميل الخطوط ديناميكياً (2 ساعة)

#### 2.1 تحميل عند فتح الكتاب
**تعديل**: `lib/FontsLoaderController.dart`

```dart
/// تحميل خطوط مستخرجة من ملف docx
Future<void> loadExtractedFonts(Map<String, String> fontPaths) async {
  for (var entry in fontPaths.entries) {
    String fontFamily = entry.key;
    String fontPath = entry.value;
    
    try {
      File fontFile = File(fontPath);
      if (!await fontFile.exists()) continue;
      
      final fontData = await fontFile.readAsBytes();
      final fontLoader = FontLoader(fontFamily);
      fontLoader.addFont(
        Future.value(ByteData.view(Uint8List.fromList(fontData).buffer))
      );
      await fontLoader.load();
    } catch (e) {
      debugPrint('⚠️ فشل تحميل خط "$fontFamily": $e');
    }
  }
}
```

#### 2.2 ربط مع مسار فتح الكتاب
**تعديل**: `lib/Services/BookProcessingService.dart` (في `_parseAndCacheBookInternal`)
- بعد استخراج الأرشيف، استدعاء `EmbeddedFontExtractor.extractEmbeddedFonts()`
- حفظ مسارات الخطوط في metadata.json
- عند إعادة فتح من الكاش: تحميل الخطوط من المسارات المحفوظة

### 3. كاش الخطوط المستخرجة (2 ساعة)

#### 3.1 هيكل الكاش
```
%AppData%/tome_ocean/<اسم_الكتاب>/
├── metadata.json
├── pages/
│   └── 0.json.gz, 1.json.gz, ...
└── fonts/                         ← جديد
    ├── KFGQPC_Uthmanic_Regular.ttf
    └── Traditional_Arabic_Bold.ttf
```

#### 3.2 تجنب الاستخراج المتكرر
- عند فتح الكتاب: فحص مجلد `fonts/` أولاً
- إذا الخطوط موجودة: تحميلها مباشرة دون إعادة استخراج
- إذا غير موجودة: استخراج من الأرشيف وحفظها

#### 3.3 كاش مشترك
- إذا نفس الخط مدمج في عدة كتب: نسخة واحدة في مجلد مشترك
- `%AppData%/tome_ocean/_shared_fonts/<hash>.ttf`
- هذا يوفر مساحة عند وجود آلاف الكتب بنفس الخطوط القرآنية

### 4. التعامل مع الخطوط المحمية (1 ساعة)

#### 4.1 خطوط بـ fontKey
- تطبيق خوارزمية فك التشفير XOR (موجودة في الكود أعلاه)
- مرجع: مواصفات ECMA-376 Part 2 (Font Obfuscation)

#### 4.2 خطوط subsetted
- `w:subsetted="true"` تعني أن الخط يحتوي فقط على الأحرف المستخدمة
- هذه تعمل بشكل طبيعي للعرض لكن قد لا تحتوي كل الأحرف

#### 4.3 خطوط غير قابلة للاستخراج
- إذا فشل الاستخراج: تسجيل تحذير وتابع بالخط البديل
- عرض رسالة للمستخدم: "بعض الخطوط لم يتم استخراجها"
