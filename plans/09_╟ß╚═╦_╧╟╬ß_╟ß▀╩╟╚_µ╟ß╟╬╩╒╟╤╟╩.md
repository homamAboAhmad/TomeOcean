# خطة 9: البحث داخل الكتاب واختصارات لوحة المفاتيح

## الوصف
تفعيل البحث داخل الكتاب المفتوح حالياً، وإضافة اختصارات لوحة المفاتيح: Ctrl+F للبحث وCtrl+W لإغلاق الكتاب.

## الوقت المتوقع: 6-8 ساعات

## السياق التقني

### البحث داخل الكتاب
حالياً يوجد أيقونة بحث في الشريط الجانبي (`BookSearchUI` في `BooksSideBarIcons.dart` سطر 79) لكنها غير مفعّلة:
```dart
// BookSearchUI موجود كملف لكن لا يحتوي على بحث فعلي
const BookSearchUI()
```

البيانات متاحة: كل صفحة مُحمَّلة كـ `WordPage` تحتوي على فقرات (`ps`) لكل منها نص (`text`).

### اختصارات لوحة المفاتيح
حالياً يوجد اختصارات في `DocViewer.dart`:
- `Ctrl++` / `Ctrl+-` للتكبير/التصغير
- `Ctrl+0` لإعادة الحجم الأصلي
- `Ctrl+Shift+C` للنسخ مع المرجع

لا يوجد `Ctrl+F` أو `Ctrl+W`.

## الخطوات التفصيلية

### 1. تفعيل البحث داخل الكتاب (4-5 ساعات)

#### 1.1 إنشاء واجهة البحث (2 ساعة)
- تعديل `lib/UI/BookSideBar/BookSearchUI.dart`:
  ```
  ┌───────────────────────┐
  │ 🔍 [_______________]  │
  │     [بحث]  [السابق] [التالي] │
  │                       │
  │ النتائج: 15 نتيجة     │
  │ ┌───────────────────┐ │
  │ │ ص 12: ...نص...    │ │
  │ │ ص 25: ...نص...    │ │
  │ │ ص 38: ...نص...    │ │
  │ └───────────────────┘ │
  └───────────────────────┘
  ```

#### 1.2 منطق البحث في الكتاب (1.5 ساعة)
- إنشاء `lib/Helpers/InBookSearchHelper.dart`:
  ```dart
  class InBookSearchHelper {
    final WordDocument wordDocument;
    
    /// البحث في جميع صفحات الكتاب
    Future<List<InBookSearchResult>> search(String query) async {
      List<InBookSearchResult> results = [];
      for (int i = 0; i < wordDocument.pageFilePaths.length; i++) {
        WordPage page = await wordDocument.getPage(i);
        String pageText = page.ps.map((p) => p.text).join(' ');
        if (pageText.contains(query)) {
          // استخراج مقتطف حول النتيجة
          results.add(InBookSearchResult(
            pageIndex: i,
            snippet: extractSnippet(pageText, query),
            occurrences: countOccurrences(pageText, query),
          ));
        }
      }
      return results;
    }
  }
  ```

#### 1.3 التنقل بين النتائج (1 ساعة)
- زر "التالي" و"السابق" للتنقل بين النتائج
- عند الضغط على نتيجة: الانتقال للصفحة عبر `_jumpToPage()`
- تمييز كلمة البحث في الصفحة المعروضة
- عداد: "النتيجة 3 من 15"

#### 1.4 خيارات البحث (0.5 ساعة)
- البحث مع/بدون تشكيل
- البحث مع/بدون همزات
- مطابقة الكلمة الكاملة

### 2. اختصار Ctrl+F (1 ساعة)

#### 2.1 إضافة الاختصار
- في `DocViewer.dart` (سطر 251):
  ```dart
  bindings: <ShortcutActivator, VoidCallback>{
    // ... الاختصارات الموجودة
    const SingleActivator(LogicalKeyboardKey.keyF, control: true):
        _openInBookSearch,
  },
  ```

#### 2.2 سلوك Ctrl+F
- إذا الشريط الجانبي مغلق: فتحه مع تبويب البحث
- إذا مفتوح: التبديل لتبويب البحث
- التركيز على حقل البحث تلقائياً
- `Escape` لإغلاق البحث

### 3. اختصار Ctrl+W (1 ساعة)

#### 3.1 إضافة الاختصار
- في `DocViewer.dart` أو `HomePage.dart`:
  ```dart
  const SingleActivator(LogicalKeyboardKey.keyW, control: true):
      _closeCurrentBook,
  ```

#### 3.2 سلوك Ctrl+W
- إغلاق الكتاب المفتوح حالياً (التبويب الحالي)
- إذا كان آخر كتاب مفتوح: العودة للشاشة الرئيسية
- تأكيد قبل الإغلاق إذا كان هناك تغييرات غير محفوظة

#### 3.3 تعديل HomePage
- إضافة دالة `_closeBook(int index)` في `HomePage.dart`
- تحديث `openedBooks` و `selectedBookP`
