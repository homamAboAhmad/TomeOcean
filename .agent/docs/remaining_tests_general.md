# قائمة الاختبارات المتبقية (عامة لكل الخطط)

## ما تم التحقق مؤخرًا
- تحذير Word (دفعة ومفرد): زر "إلغاء" يغلق الحوار قبل البدء، و"متابعة" تكمل المعالجة.
- الإلغاء أثناء المعالجة/الانتظار (دفعة ومفرد): يتوقف التنفيذ، تظهر حالة "تم الإلغاء"، ويتوفر زر "إعادة المحاولة" للعناصر الملغاة/الفاشلة.
- تنظيف `_temp_*.docx` عند الإقلاع (PathExistsException لم يعد يظهر في التشغيل العادي).

## ما يحتاج اختباراً (عام)
1) **سيناريو الملفات المؤقتة يدويًا**
   - ضع ملف `_temp_*.docx` يدويًا في `BOOKS_FOLDER_PATH` قبل التشغيل.
   - المتوقع: يُحذف عند الإقلاع ولا يظهر PathExistsException أثناء النسخ.

2) **وضع الإصدار Release (exe)**
   - ابنِ `pageRender.exe` محدثًا وشغّل التطبيق في وضع Release (مع `USE_PYTHON = kDebugMode` سيصبح false تلقائيًا).
   - تحقق أن التحذيرات، الإلغاء، والمسار الكامل يعمل بنفس سلوك التطوير.

3) **إعادة المحاولة بعد الإلغاء/الفشل**
   - بعد إلغاء دفعة أو فشل عنصر، استخدم أزرار "إعادة المحاولة" (لكل عنصر أو للكل) وتأكد من الاستئناف دون حالات معلقة.

4) **مراقبة الأداء/الثبات**
   - جرّب دفعة بملفات كبيرة ومتعددة للتأكد من عدم حدوث تجمدات أو تسربات موارد (Word/Processes) تحت الضغط.
