# خطة الاختبارات المتبقية (الخطة 1)

## تم التحقق
- [x] تحذير Word (دفعة): "إلغاء" يغلق الديالوج ولا يبدأ المعالجة، "متابعة" تكمل التشغيل.
- [x] تحذير Word (مفرد): "إلغاء" يغلق الديالوج ولا يبدأ المعالجة، "متابعة" تكمل التشغيل.
- [x] الإلغاء أثناء المعالجة/الانتظار في الدفعة: يتوقف التنفيذ، العناصر تظهر "تم الإلغاء"، ويظهر زر "إعادة المحاولة" للعناصر الملغاة/الفاشلة.

## ما يحتاج اختباراً
1) **سيناريو PathExistsException القديم**
   - حاول تشغيل استيراد كتاب مع وجود ملف `_temp_*.docx` متعمد في `BOOKS_FOLDER_PATH` قبل التشغيل.
   - المتوقع: يُحذف الملف المؤقت عند الإطلاق، ولا يظهر الخطأ عند النسخ.

2) **وضع الإصدار Release (exe)**
   - ابْنِ `pageRender.exe` محدثاً ثم شغّل التطبيق في وضع Release (مع `USE_PYTHON = kDebugMode` يصبح false تلقائياً).
   - تأكد أن التحذير، الإلغاء، ومسار التنفيذ يعملون بالـ exe بنفس سلوك التطوير.

3) **إعادة المحاولة بعد الإلغاء/الفشل**
   - بعد إلغاء دفعة أو فشل عنصر، استخدم زر "إعادة المحاولة" لكل عنصر أو زر "إعادة المحاولة (الكل)" للتأكد من استئناف صحيح دون بقاء حالات معلقة.
